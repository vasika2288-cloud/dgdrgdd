# Meow Squad (Кошачий Отряд)

Динамичный браузерный 2D survivors-рогалик на чистом HTML5 Canvas и JavaScript, без сторонних библиотек и сборки.

Игрок управляет волшебником, вокруг которого кружит отряд боевых котов-магов. Коты сами атакуют крысиную орду, и у каждого своя магия. Нужно собирать кристаллы опыта, прокачивать котов и продержаться 6 минут, одолев Крысиного Короля Мракуса.

## Лобби

Перед забегом игрок попадает в лобби с мета-прогрессией:

- **Бой.** Пять глав с растущей сложностью и наградами, сундуки за 2:00, 4:00 и победу, выбор главы стрелками или свайпом, кнопка «В бой» за ⚡5. На фоне бегает отряд.
- **Ресурсы.** Энергия (⚡, до 30, +1 каждые 5 минут), рыбки (🐟, основная валюта), кристаллы (💎, редкая валюта), уровень профиля (каждый новый уровень даёт +10 ⚡).
- **Отряд.** 8 котов с уровнями 1–10 (+10% урона за уровень) и выбор лидера, с которым начинается забег.
- **Эволюция.** Постоянные таланты: здоровье, урон, броня, скорость, радиус сбора. Они открываются с ростом уровня профиля.
- **Лавка.** Бесплатный ежедневный улов, корзинки котиков, энергия и рыбки за кристаллы. Это внутриигровая валюта, реальных платежей нет.
- **Испытания.** Ежедневная «Ночь Мракуса»: враги ×2, награда ×3. Ещё два режима анонсированы.
- **Ежедневная награда** (7-дневный цикл), **задания дня**, **рекорды**, **профиль** с именем и сбросом прогресса, **звук**.

После каждого забега экран результатов показывает начисленные рыбки и опыт, открытые главы и новые рекорды.

## Технологии

- HTML5 Canvas 2D: процедурная отрисовка котов, врагов и эффектов.
- Vanilla JavaScript (ES6+): игровой цикл, spatial hashing, Web Audio синтезатор.
- CSS3: адаптивный интерфейс лобби и HUD с учётом safe-area для мобильных.
- `localStorage`: профиль игрока и рекорды хранятся в браузере.
- Netlify: статический хостинг без шага сборки.

## Локальный запуск

```bash
netlify dev --port 8889
# или
python3 -m http.server 8889
```

Откройте `http://localhost:8889`.
